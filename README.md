# 🌟 Featured Project

## 🏋️ MomentumX — Fitness & Gym Management Platform

### 📖 Overview

MomentumX is a full-stack fitness and gym management platform designed to streamline the experience for **Members**, **Trainers**, and **Administrators**. The platform features secure authentication, role-based dashboards, online class booking, trainer management, community engagement, and integrated online payments.

---

### 🚀 Live Demo

🔗 https://momentum-x-client.vercel.app/

---

### 🛠 Tech Stack

**Frontend**
- Next.js
- React
- Tailwind CSS
- DaisyUI
- Framer Motion
- TanStack Query
- React Hook Form
- Axios
- SweetAlert2

**Backend**
- Node.js
- Express.js
- MongoDB
- Better Auth
- JWT Authentication
- ImageBB API
- Stripe Checkout

---

### ✨ Key Features

- 🔐 Secure authentication with Better Auth & JWT
- 👥 Role-based dashboards for Members, Trainers & Admin
- 💳 Stripe-powered class booking and payment system
- 🏋️ Trainer application and approval workflow
- 💬 Community forum with ImageBB image uploads
- ⭐ Save favourite classes for quick access
- 📱 Fully responsive UI for desktop, tablet & mobile
- 🚀 Production deployment using Vercel & Render
